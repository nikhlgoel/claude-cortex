# Live Pairing Session

Start an interactive, collaborative pairing workflow on the current objective.

## Instructions for Claude

1. Activate the `live-pairing` skill protocol.
2. Outline the overall goal and present **Step 1** with your proposed solution.
3. Ask the user for their thoughts or approval.
4. When the user agrees or provides feedback, **immediately auto-start** the implementation, verify the code, and proactively ask for extra amendments!
