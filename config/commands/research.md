# Frontier Research & Discovery

Research a cutting-edge technological or scientific topic beyond conventional boilerplate:
1. Query arXiv preprints and state of the art literature.
2. Deconstruct the problem to physical and mathematical first principles.
3. Formulate a novel hypothesis and generate a runnable computational simulation testbench.
4. Persist findings to `research/<topic>/` and synchronize with the Memory Palace.

## Usage
```bash
/research "quantum error correction in fault-tolerant qubits"
/research "linear attention and state space models"
/research "sub-quadratic polynomial commitment folding"
```
